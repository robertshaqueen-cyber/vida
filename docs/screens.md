## S3 主界面布局

```
┌──────────────────────────────────────────────────────────────┐
│ [主机×] [设置×] [+] [⊞]                     [⚙] [🔒]      │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                    当前标签页的内容                            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

- **标签页**：每个主机连接一个标签页，可关闭（×）；设置、新增主机也是标签页
- **⊞ 快速连接面板**：浮动遮罩层，居中显示搜索框 + 最近访问 + 全部主机 + 新增主机，
  打开时自动聚焦搜索框，全键盘可操作
- **⚙ 设置**：打开设置标签页
- **🔒 锁定**：锁定金库返回解锁页
